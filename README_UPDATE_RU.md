# WorkShift — обновление для Supabase/PostgreSQL

Эти файлы заменяют `app.py`, `requirements.txt`, `render.yaml` и `.env.example` в текущем репозитории.

## Важно
- Скопируйте `app.py`, `requirements.txt`, `render.yaml` и `.env.example` в корень GitHub-репозитория, заменив одноимённые файлы.
- `static/index.html` должен остаться внутри папки `static`.
- Никогда не публикуйте токен Telegram или `DATABASE_URL` в GitHub.
- В Render → Environment добавьте `BOT_TOKEN`, `APP_URL`, `DATABASE_URL`.
- В `DATABASE_URL` используйте URI Supabase Session pooler, с паролем базы. Если пароль содержит специальные символы, их нужно percent-encode.
- Приложение создаёт нужные таблицы в Supabase при старте; SQL вручную запускать не требуется.

## Ограничение напоминаний
Бесплатный Render может засыпать после простоя. Пока сервис спит, проверки напоминаний не выполняются. Этот вариант сохраняет расписания в PostgreSQL, но не гарантирует своевременные уведомления. Кроме того, версия-пример предполагает начало смены в 08:00; прежде чем использовать в реальной работе, нужно подтвердить время начала смены и настроить внешний бесплатный планировщик/проверку.
