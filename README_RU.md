# WorkShift — публичный Telegram-бот графика работы

Проект для разработки с Android: Telegram-бот + Telegram Mini App + SQLite.

## Возможности
- персональные графики 2/2, 5/2, сутки через трое;
- произвольный график: отметить рабочие даты вручную;
- месячный календарь;
- индивидуальные напоминания накануне и за заданное количество часов;
- хранение настроек отдельно для каждого Telegram-пользователя.

## Важно про бесплатный хостинг
Бесплатные веб-сервисы могут «засыпать». Пока приложение спит, напоминания могут опаздывать или пропускаться. Для надёжных уведомлений нужен постоянно работающий хостинг. Не обещайте пользователям гарантированные уведомления на бесплатном тарифе.

## Структура
- `app.py` — API, Telegram-бот и планировщик
- `static/index.html` — интерфейс Mini App
- `requirements.txt` — зависимости
- `render.yaml` — пример настройки Render
- `.env.example` — переменные окружения

## Часть 1. Создать бота
1. В Telegram откройте `@BotFather`.
2. Отправьте `/newbot`, выберите имя и username.
3. Скопируйте токен. Никому его не отправляйте.
4. В BotFather отправьте `/setmenubutton`, выберите своего бота, затем задайте URL Mini App после публикации сайта. Альтернатива — `/setdomain` и домен веб-приложения.

## Часть 2. Подготовить проект на Android
Самый простой способ — GitHub через браузер:
1. Создайте аккаунт на GitHub и новый репозиторий.
2. Загрузите файлы из архива, сохраняя структуру папок.
3. В `app.py` код не меняйте для обычного запуска.
4. Создайте сервис хостинга из репозитория.

Можно редактировать файлы через браузер GitHub или мобильный редактор кода. Termux не обязателен, потому что сборка происходит на сервере.

## Часть 3. Развернуть на Render (пример)
1. Откройте https://render.com/ и войдите через GitHub.
2. Создайте **Web Service** из репозитория.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
5. Добавьте Environment Variables:
   - `BOT_TOKEN` — токен от BotFather
   - `APP_URL` — полный HTTPS URL сервиса, например `https://your-service.onrender.com`
   - `TIMEZONE` — часовой пояс по умолчанию, например `Europe/Warsaw`
   - `DATABASE_PATH` — `data/workshift.sqlite3`
6. Если есть выбор диска, подключите persistent disk и укажите путь к базе на нём. Без постоянного диска данные SQLite могут потеряться при пересборке/перезапуске.
7. После успешного запуска откройте `https://your-service.onrender.com/health`. Должно показать `{"ok":true}`.

Условия бесплатного тарифа меняются; проверьте их перед публикацией. Сервис, который засыпает, не подходит для гарантированных напоминаний.

## Часть 4. Подключить Mini App
1. В `@BotFather` используйте `/setmenubutton`.
2. Выберите бота, настройте текст кнопки, укажите `APP_URL`.
3. Откройте бота, нажмите `/start`, затем кнопку меню.
4. В Mini App нажмите «Сохранить настройки». Если всё настроено верно, данные сохранятся для вашего Telegram-аккаунта.

## Как работает график
Для циклических графиков пользователь выбирает дату, которая точно является рабочим днём:
- 2/2: два рабочих, два выходных;
- 5/2: пять рабочих, два выходных;
- сутки через трое: один рабочий день, затем три выходных.

Для ручного графика пользователь выбирает рабочие даты в календаре. Настройки и рабочие даты хранятся отдельно для каждого Telegram ID.

## Безопасность и эксплуатация
- Не вставляйте токен в HTML, GitHub или публичные сообщения.
- Храните `BOT_TOKEN` только в секретах хостинга.
- Mini App передаёт Telegram `initData`; сервер проверяет подпись перед сохранением настроек.
- Перед широким запуском добавьте резервное копирование базы, мониторинг ошибок и политику конфиденциальности.
- Это стартовый MVP. Перед публичным масштабным использованием протестируйте смену часовых поясов, переходы на летнее/зимнее время, восстановление базы и поведение при простое сервера.
